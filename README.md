# Music Mood Matcher
**Team: The Overfitters** 

> Describe how you feel. Get songs that match your mood — with explanations.

---

## What it does

Music Mood Matcher takes a natural language mood description from the user (e.g. *"I feel melancholic and nostalgic, rainy Sunday morning"*) and returns a ranked list of songs that match that emotional state, each with a reason explaining why it fits.

The system combines **semantic search over song lyrics** (RAG) with a **locally-hosted language model** (via LM Studio) to produce grounded, explainable recommendations — no cloud APIs, fully offline.

## Setup

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Download the dataset
- Go to: https://www.kaggle.com/datasets/imuhammad/audio-features-and-lyrics-of-spotify-songs
- Download the CSV and place it at: `data/spotify_lyrics.csv`

### 3. Preprocess and balance the dataset
```bash
python src/preprocess.py
python src/genre_balance.py
```
This produces `data/balanced.csv` with 5,174 songs balanced across 6 genres.

### 4. Build the vector index
```bash
python src/embeddings.py
```
Downloads `all-MiniLM-L6-v2` (~90MB, first run only) and embeds all lyrics into ChromaDB. Takes ~25 seconds.

### 5. Set up LM Studio
- Download [LM Studio](https://lmstudio.ai)
- Search for and download **LLaMA 3.2 3B Instruct** (2GB)
- Go to the **Developer** tab → **Local Server** → load the model → **Start Server**
- Server runs at `http://localhost:1234`

### 6. Run the app
Open two terminals:

```bash
# Terminal 1 — backend
uvicorn main:app --reload

# Terminal 2 — frontend
streamlit run app.py
```

Open `http://localhost:8501` in your browser.

## Pipeline

```
User mood input
        ↓
Toxicity filter          keyword + phrase + regex blocking
        ↓
Dataset coverage check   detects missing genres, shows fallback notice
        ↓
Mood profile detection   maps keywords → audio feature ranges
        ↓
Hybrid RAG retrieval     ChromaDB semantic search + genre filter
        ↓
Audio feature filter     valence, energy, danceability ranges
        ↓
LM Studio (LLaMA 3.2 3B) generates explanations for each song
        ↓
Hallucination guard      cross-checks suggestions against dataset
        ↓
Song recommendations
```

---

## Key Features

- **Hybrid retrieval** — combines semantic lyric similarity with audio feature filtering so "dancing bachata" returns high-danceability latin tracks, not just any song mentioning dancing
- **Dataset-aware fallbacks** — automatically detects when a requested genre (jazz, metal, bachata, k-pop) is not in the dataset and shows a tailored notice with the closest available alternative
- **Pinned songs** — special handling for edge cases (e.g. Romanian music always surfaces Dragostea Din Tei by O-Zone)
- **Toxicity filter** — three-layer input safety (keyword blocklist, phrase matching, obfuscation patterns)
- **Hallucination guard** — verifies every LLM-suggested song exists in the dataset before returning it
- **Fully offline** — no cloud APIs, all inference runs locally via LM Studio

---

## Limitations

- No bachata, jazz, country, metal, or k-pop in the dataset (only 6 Spotify playlist genres)
- LLaMA 3.2 3B is a small model — a larger model would produce better explanations
- Mood detection is keyword-based, not semantic — "I feel like Billie Eilish" won't trigger a profile
- 5,174 songs is a small corpus — a larger dataset would improve recommendation diversity
- Romanian music is almost absent (only Dragostea Din Tei by O-Zone)
